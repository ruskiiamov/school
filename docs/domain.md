# Доменная модель

Основана на решениях D-001…D-067. Таблицы итерации 2 (`users` с `active`,
`subjects`, `work_types`, `classes`, `class_students`, `parent_children`,
`teaching_assignments`) созданы миграцией `00002_catalog.sql`, таблицы
итерации 3 (`substitutions`, `lessons`, `marks`, `lesson_students`) —
`00003_journal.sql`, таблицы итерации 5 (`homework`, `homework_files`) —
`00004_homework.sql`.
Внешних ключей нет ([D-018], CLAUDE.md):
целостность держит сервисный слой, для каждой связи ниже указано, кто чистит
зависимые строки.

## Глоссарий

| Термин | Смысл |
|---|---|
| Учебный год | число — год начала («2026» показывается как «2026/2027»); текущий вычисляется по «сегодня» и месяцу `school.year_start_month` из конфига (D-042) |
| Класс | группа учеников внутри одного учебного года, например «7А» 2026/2027 |
| Предмет | «Алгебра», «История»; общий справочник школы |
| Нагрузка | связь учитель × предмет × класс: кто ведёт предмет в классе |
| Замена | учитель временно ведёт чужие предмет и класс в заданный период |
| Урок | факт занятия: класс + предмет + дата; заводит учитель |
| Тип работы | справочник видов активности: «ответ на уроке», «контрольная», «ДЗ письменное»… |
| Оценка | целое 1–5 ученику за урок с типом работы и необязательной подписью «за что» |
| Запись об уроке | комментарий учителя ученику за урок и флаг отсутствия |
| ДЗ | домашнее задание, заданное на уроке: текст, файлы, необязательный срок |
| Перевод | создание классов нового года из классов прошлого с копированием состава |
| Журнал | рабочее место учителя: урок → ученики → оценки |
| Дневник | рабочее место ученика/родителя: день → уроки → оценки, комментарий, ДЗ |

## Сущности

Из итерации 1 — `users` и `sessions`; `login_devices` — знакомые
устройства входа (хеш токена cookie `device`, `user_id`, D-085). У всех справочников `active INTEGER`
(1/0) вместо удаления. Календарные даты (уроки, сроки ДЗ, периоды) хранятся
как `TEXT` в формате `YYYY-MM-DD` в часовом поясе из конфига (D-021);
моменты времени, как и раньше, — миллисекунды Unix.

```
users                id, login, password_hash, full_name, role, active, created_at, updated_at
subjects             id, name, active, created_at, updated_at
classes              id, year, name, graduating, active, created_at, updated_at
                                                                UNIQUE (year, name)
class_students       class_id, student_id                       PK (class_id, student_id)
parent_children      parent_id, student_id                      PK (parent_id, student_id)
teaching_assignments id, teacher_id, subject_id, class_id       UNIQUE (subject_id, class_id)
substitutions        id, class_id, subject_id, teacher_id, start_date, end_date, created_at, updated_at
work_types           id, name, sort_order, active, created_at, updated_at
lessons              id, class_id, subject_id, teacher_id, date, topic, created_at, updated_at
                                                                UNIQUE (class_id, subject_id, date)
marks                id, lesson_id, student_id, work_type_id, value, label, created_at, updated_at
lesson_students      lesson_id, student_id, absent, comment, updated_at
                                                                PK (lesson_id, student_id)
homework             lesson_id (PK), text, due_date, created_at, updated_at
homework_files       id (TEXT PK), lesson_id, name, size, content_type, created_at
```

Пояснения.

- Текущий учебный год — `school.CurrentYear()`: год «сегодня» в часовом поясе
  конфига, а если месяц «сегодня» раньше `school.year_start_month` — предыдущий. Журнал,
  дневник и списки выбора по умолчанию работают с текущим годом; таблицы у
  года нет (D-042).
- `classes.year` — год начала учебного года; класс живёт один год.
  Списки классов идут в естественном порядке имён (`CAST(name AS
  INTEGER)`, потом строка, D-070).
  Колонка `graduating` осталась в схеме, но не используется (D-071).
  Название уникально внутри года.
- `class_students` — состав на год. Ученик состоит не более чем в одном
  активном классе текущего года (правило сервиса). Ученик, покинувший школу,
  деактивируется как пользователь, строка членства остаётся: старые уроки
  должны показывать его оценки. История «в каком классе был» — членства в
  классах прошлых лет.
- `teaching_assignments` — один учитель на (класс, предмет). Смена учителя —
  замена строки. Нагрузка привязана к классу, а класс — к году, поэтому
  нагрузка тоже годовая.
- `substitutions` — `end_date` может быть NULL («до отмены»). Периоды по одной
  паре (класс, предмет) не пересекаются. Ссылка на класс и предмет, а не на
  нагрузку: смена основного учителя не ломает действующие замены. Замена
  заводится только на активный класс текущего года; правится только период
  (D-058).
- `work_types` — стартовый набор заводится миграцией: «Ответ на уроке»,
  «Классная работа», «Самостоятельная работа», «Контрольная работа»,
  «Домашняя работа (письменная)», «Домашняя работа (устная)». Админ добавляет,
  переименовывает, деактивирует и меняет порядок.
- `lessons.date` — дата урока, не ограничена (D-022). `teacher_id` — кто
  провёл (автор); показывается в дневнике (D-032). Урок создаётся учителем
  явно из формы «класс, предмет, дата»; повторное открытие той же тройки
  открывает существующий урок.
- `marks.label` — свободный текст «за что», может быть пустым. Число оценок
  ученику за урок не ограничено.
- `lesson_students` — строка появляется, когда есть что хранить (комментарий
  или отсутствие); сохранение пустого комментария со снятым флагом удаляет
  строку. `absent=1` не запрещает оценки. Комментарий — до 500 символов,
  подпись оценки — до 100, тема урока — до 200 (D-059).
- `homework` — одно ДЗ на урок; строка есть, только пока не пусты текст
  или срок (`due_date` может быть NULL, срок — информация, ничего не
  фильтрует, D-065). Текст — до 2000 символов, многострочный.
- `homework_files` ссылаются на урок, а не на строку `homework`: файлы
  живут и без текста. `id` — случайные 16 байт в hex, он же имя файла на
  диске `<files.dir>/<id>`. Оригинальное имя — в `name` (до 200 символов),
  отдаётся через `Content-Disposition: attachment`; `content_type`
  определён сервером по содержимому. Лимиты — в конфиге `files`: размер
  файла (по умолчанию 10 МБ), число файлов на урок (10).

## Инварианты (проверяет сервис)

1. `marks.value` ∈ {1,2,3,4,5}.
2. Оценка, запись об уроке и ДЗ ссылаются на существующий урок; новая оценка
   и запись об уроке — только ученику из текущего состава класса урока
   (деактивированный ученик остаётся в составе); оценки ученика, вышедшего
   из класса, можно править и удалять (D-058).
3. Создать урок может учитель с нагрузкой на (класс, предмет) или учитель с
   заменой по этой паре, чей период включает дату урока (D-031).
4. `work_type_id` в новой оценке — активный тип; в старых оценках тип может
   быть уже деактивирован и по-прежнему отображается.
5. Деактивированный пользователь не может войти: при деактивации удаляются его
   сессии (`SessionRepo.DeleteByUser`) и знакомые устройства
   (`LoginDeviceRepo.DeleteByUser`); устройства без пользователя чистит
   уборка сессий.
6. Ученик — не более чем в одном активном классе текущего года; периоды замен
   по паре (класс, предмет) не пересекаются.
7. Класс, у которого есть строки `class_students`, не деактивируется (D-052);
   у пары (класс, предмет) один учитель — новое назначение заменяет строку
   (`UNIQUE (subject_id, class_id)`, D-049).

## Права

| Действие | admin | teacher | student | parent |
|---|---|---|---|---|
| справочники: предметы, классы, пользователи, нагрузка, замены, типы работ, перевод | CRUD | — | — | — |
| создать урок | — | нагрузка или действующая замена | — | — |
| журнал урока: оценки, комментарий, отсутствие, ДЗ, файлы | чтение | автор урока или текущий учитель по нагрузке | — | — |
| дневник | любого ученика, чтение | — | только свой | только своих детей |
| скачать файл ДЗ | да | кто видит урок | кто видит урок в дневнике (состав класса или свои оценки/запись, D-023) | через любого своего ребёнка |

«Текущий учитель по нагрузке» — строка `teaching_assignments` для (класс,
предмет) урока. «Ученик класса урока» — есть строка `class_students` для класса
урока. В списке класс/предмет журнала учитель видит свою нагрузку и замены,
чей период ещё не закончился, только по активным классам текущего года и
активным предметам. Проверки — в сервисном слое `internal/journal`;
обработчик получает `journal.ErrForbidden` и отвечает 404 (не раскрывать
существование чужих данных, D-058). Дневник ученика видит сам ученик,
его родители и админ (`/admin/diary`, D-061); в дневнике — уроки классов,
где ученик состоит, плюс уроки с его оценками или записью (D-023).
Страницы урока для админа нет: оценки он читает через дневник (D-062).

## Перевод классов (D-028)

Действие админа в текущем году (`/admin/classes/transfer`, D-068): для
каждого активного класса прошлого года (`текущий − 1`) предлагается новый
класс с именем, где ведущее число увеличено на единицу («7А» → «8А»; без
числа — то же имя); у класса с ведущим числом 11 галочка «Переводить»
по умолчанию снята с подписью «выпускной» (D-070, D-071). Состав копируется без деактивированных учеников и без
тех, кто уже состоит в классе текущего года; нагрузка не копируется.
Админ правит предложение (галочки классов и учеников, имена) и
подтверждает — всё создаётся одной транзакцией (`ClassRepo.Transfer`).
Повторный запуск возможен: класс, чьё предложенное имя уже занято в
текущем году, показывается как пропущенный. Пометки «выпуск» нет,
выпускники не деактивируются (D-071).

## Прошлые годы (D-068)

Уроки, оценки и записи прошлых лет никуда не деваются: дневник за день
принимает любую дату, а сводки учителя и админа, «Оценки» ученика и
поиск дневников админом получают параметр `year` (селект «Учебный год»
всегда; годы — `school.ClassYears`: годы существующих классов, текущий и
следующий, D-070, D-071); те же годы — вкладки «Классов».
Пары учителя за прошлый год — по нагрузке на классы того года; период
зажимается в границы выбранного года. Страница урока прошлого года
открывается по обычным правам D-031, правка по времени не ограничена
(D-016).

## Удаление и уборка

Явные удаления (в одной транзакции, сервисом):

| Удаляем | Заодно чистим |
|---|---|
| оценку | ничего |
| файл ДЗ | строку `homework_files` и файл на диске (сначала строка, потом файл) |
| ДЗ (пустые текст и срок) | только строку `homework`; файлы остаются |
| урок (только пустой — без оценок и записей, D-024) | `homework`, `homework_files` в одной транзакции, затем файлы с диска |
| нагрузку | ничего: уроки остаются у автора |
| замену | ничего: уроки остаются у автора |
| членство ученика в классе | ничего: оценки остаются |

Классы, предметы, пользователи, типы работ не удаляются — деактивируются
(D-018).

Периодическая уборка: `journal.Service.RunCleanup` раз в
`journal.cleanup_interval` (по умолчанию сутки) удаляет `marks` и
`lesson_students` без урока (D-059), `homework` и `homework_files` без
урока вместе с файлами на диске, файлы на диске без строки — только
старше суток и только если в `homework_files` есть хоть одна строка
(D-086); строки `homework_files` без файла остаются и пишутся в лог
предупреждением (D-065).
