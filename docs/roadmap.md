# Roadmap

Каждая итерация — вертикальный срез: миграция → репозиторий → сервис →
страницы → тесты через `newTestServer`. Итерация закрывается, когда сквозной
сценарий из `scenarios.md` проходит руками на телефоне и десктопе и покрыт
тестом. Итерация 1 (вход, дашборд) готова.

## Итерация 2 — справочники админа

Идёт по вертикальным срезам. Готово (2026-09-13): фундамент — конфиг
`timezone` и `school.year_start_month`, миграция со всеми таблицами итерации,
`active` у `users`, меню по ролям с заглушками «Журнал» и «Дневник»,
`requireRole` → 404, пакет `school` с вычислением текущего года (D-042). Дальше по порядку: предметы и типы работ → классы →
пользователи → состав/нагрузка/дети → свой пароль → дашборд.

- Конфиг `timezone` (D-021) и `school.year_start_month` (D-042). ✔
- `active` у `users`; страницы «Предметы», «Классы», «Учителя», «Ученики»,
  «Родители» (создание, правка, деактивация), задание пароля админом,
  смена своего пароля любым пользователем (D-025).
- Состав класса, привязка детей к родителю, нагрузка учителя.
- Справочник типов работ со стартовым набором из миграции.
- Дашборд показывает реальные счётчики вместо `PlaceholderStats`.
- Вне итерации: перевод классов, замены, импорт из файла.

## Итерация 3 — журнал учителя

- Пункт меню «Журнал»: форма класс + предмет + дата из своей нагрузки и
  действующих замен → урок (создать или открыть), тема урока.
- Страница урока: слева ученики класса (D-023), справа выбранный ученик:
  оценки (тип, значение, подпись), флаг отсутствия, комментарий.
  HTMX-фрагменты с полноценным fallback без JS.
- Права по D-031; страница админа «Замены» (D-030); удаление пустого урока.
- Список своих уроков по классу (последние даты) для быстрой навигации.
- Вне итерации: ДЗ, сводные таблицы.

## Итерация 4 — дневник ученика и родителя

- Пункт меню «Дневник»: выбор даты (по умолчанию сегодня), слева уроки дня
  с ФИО проводившего (D-032), справа оценки, отсутствие, комментарий по уроку.
- Родитель: переключатель детей.
- Проверка доступа: чужой дневник и чужой урок → 404. Тесты на это обязательны.
- Вне итерации: ДЗ, средний балл.

## Итерация 5 — домашнее задание

- Конфиг `files.dir`, лимиты; в журнале урока — блок ДЗ: текст, срок, файлы
  (загрузка, удаление).
- В дневнике — ДЗ по уроку и список актуальных ДЗ; скачивание через
  обработчик с проверкой доступа.
- Уборка осиротевших файлов.

## Итерация 6 — сводные представления

- Учителю: разворот «ученики × даты» по классу и предмету за период.
- Ученику/родителю: все оценки по предметам за период, средний балл.
- Здесь же, если понадобится: вес типа работы.

- Дневник за прошлые годы: выбор года и класса.
- Делать ближе к концу первого учебного года.
