# Roadmap

Каждая итерация — вертикальный срез: миграция → репозиторий → сервис →
страницы → тесты через `newTestServer`. Итерация закрывается, когда сквозной
сценарий из `scenarios.md` проходит руками на телефоне и десктопе и покрыт
тестом. Итерация 1 (вход, дашборд) готова.

## Итерация 2 — справочники админа

Идёт по вертикальным срезам. Каждый срез: миграция/репозиторий → сервис →
view-модели и шаблоны → обработчики и маршруты → тесты → `make check`;
срезы идут по порядку, каждый оставляет проект зелёным.

0. **Фундамент** — готов (2026-09-13): конфиг `timezone` и
   `school.year_start_month`, миграция со всеми таблицами итерации, `active`
   у `users`, меню по ролям с заглушками «Журнал» и «Дневник», `requireRole`
   → 404, пакет `school` с вычислением текущего года (D-042).
1. **Учебные годы** — сделан и удалён: по D-042 год не сущность.
2. **Предметы и типы работ** — готов (2026-09-13, S-2.3, S-2.4): одна
   страница на справочник, правка в строке, деактивация, переключатель
   «Показать удалённые», имя уникально среди активных, порядок типов работ
   стрелками. Здесь появился паттерн форм: `validation.Errors` (D-041),
   строки-формы с HTMX-фрагментом и fallback на редирект (D-043).
3. **Классы** (S-2.5, S-2.16 имя): список по году с селектором (годы
   существующих классов, текущий и следующий), карточка класса с двумя
   пустыми блоками под срез 5.
4. **Пользователи** (S-2.6, S-2.10, S-2.11, S-2.13, S-2.16 логин): в `auth`;
   разделы «Учителя», «Ученики», «Родители», логин из ФИО транслитом (D-036),
   одноразовая страница с паролем (D-039), задание пароля админом,
   деактивация с удалением сессий, поиск по ФИО без учёта регистра.
5. **Состав класса, нагрузка, дети родителя** (S-2.7, S-2.8, S-2.9): блоки
   на карточке класса и странице родителя, HTMX-фрагменты с fallback на
   редирект.
6. **Свой пароль** (S-2.12): `/account/password` для любой роли, остальные
   сессии сбрасываются.
7. **Дашборд** (S-2.14, S-2.15): реальные счётчики текущего года вместо
   `PlaceholderStats`, баннер «нет классов», другим ролям — ссылка на свой
   раздел.
8. **Документы**: `decisions.md`, `ui.md`, `CLAUDE.md` и этот файл по факту.

Вне итерации: перевод классов, замены, импорт из файла.

## Итерация 3 — журнал учителя

- Пункт меню «Журнал»: форма класс + предмет + дата из своей нагрузки и
  действующих замен → урок (создать или открыть), тема урока.
- Страница урока: слева ученики класса (D-023), справа выбранный ученик:
  оценки (тип, значение, подпись), флаг отсутствия, комментарий.
  HTMX-фрагменты с полноценным fallback без JS.
- Права по D-031; страница админа «Замены» (D-030); удаление пустого урока.
- Список своих уроков по классу (последние даты) для быстрой навигации.
- Вне итерации: ДЗ, сводные таблицы.

## Итерация 4 — дневник ученика и родителя

- Пункт меню «Дневник»: выбор даты (по умолчанию сегодня), слева уроки дня
  с ФИО проводившего (D-032), справа оценки, отсутствие, комментарий по уроку.
- Родитель: переключатель детей.
- Проверка доступа: чужой дневник и чужой урок → 404. Тесты на это обязательны.
- Вне итерации: ДЗ, средний балл.

## Итерация 5 — домашнее задание

- Конфиг `files.dir`, лимиты; в журнале урока — блок ДЗ: текст, срок, файлы
  (загрузка, удаление).
- В дневнике — ДЗ по уроку и список актуальных ДЗ; скачивание через
  обработчик с проверкой доступа.
- Уборка осиротевших файлов.

## Итерация 6 — сводные представления

- Учителю: разворот «ученики × даты» по классу и предмету за период.
- Ученику/родителю: все оценки по предметам за период, средний балл.
- Здесь же, если понадобится: вес типа работы.

- Дневник за прошлые годы: выбор года и класса.
- Делать ближе к концу первого учебного года.
