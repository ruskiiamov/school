# Сценарии

Формат: `S-<итерация>.<номер>`, роль, «дано / когда / тогда», критерии
приёмки. Из каждого сценария пишется хотя бы один тест в
`internal/server/server_test.go` через `newTestServer`. Негативные сценарии
(чужие данные, чужая роль) обязательны.

Общие правила для всех сценариев итерации 2:

- Страницы `/admin/*` доступны только роли admin; другим ролям и анонимам —
  404 (аноним предварительно уходит на `/login`, как сейчас).
- Каждая форма отправляется обычным POST и работает без JS.
- Ошибки валидации показываются на той же странице, введённые значения
  сохраняются в полях.
- После успешного POST — редирект на страницу списка или карточки
  (PRG), HTMX-запросы получают `HX-Redirect` (см. `s.redirect`).
- Вёрстка проверяется на ширине 375 px и 1280 px.

## Итерация 2 — справочники админа

### S-2.1 · система · Текущий учебный год по конфигу

Дано: `school.year_start_month: 8`. Когда сегодня 31.07.2026 — текущий год
2025 («2025/2026»); 01.08.2026 и 15.03.2027 — 2026 («2026/2027»). Год
считается в `timezone` из конфига. Покрывается тестом `school.YearAt`.

### S-2.2 · отменён (D-044) · Классы следующего года заранее

Классы создаются только в текущем году. Школа, которой нужно готовить
классы раньше 1 августа, сдвигает `school.year_start_month` в конфиге.

### S-2.3 · admin · Предметы

Создать «Алгебра», переименовать, деактивировать. Деактивированный не
показывается в списке без переключателя и недоступен для новой нагрузки;
существующие нагрузки и уроки с ним остаются. Имя уникально среди активных.

### S-2.4 · admin · Типы работ

Список содержит шесть стартовых типов из миграции в заданном порядке.
Админ добавляет «Проект» (встаёт в конец), переименовывает в строке,
двигает стрелками «выше»/«ниже», деактивирует. Деактивированный тип не предлагается в новых
оценках.

### S-2.5 · admin · Создать класс

Дано: сегодня 15.09.2026, текущий год 2026/2027. Когда админ создаёт класс
«7А». Тогда класс в списке текущего года. Классы создаются только в текущем
году; имя уникально внутри года. Список классов фильтруется по году
(вкладки — годы существующих классов и текущий), по умолчанию текущий;
на вкладках прошлых лет формы добавления нет.

### S-2.6 · admin · Создать учителя, ученика, родителя

Форма: ФИО, логин (предзаполняется транслитом ФИО, при коллизии — суффикс
`2`, `3`…), пароль. Для ученика — необязательный выбор класса текущего года.
После создания — страница «Пользователь создан» с логином и паролем один раз.

Критерии: логин уникален среди всех пользователей (включая неактивных);
пароль не короче 8 символов; роль задаётся разделом, в форме её нет.

### S-2.7 · admin · Состав класса

На странице класса: список учеников, поле «добавить ученика» (выбор из
активных учеников, не состоящих ни в одном классе текущего года), кнопка
«убрать». Ученик не может быть в двух классах одного года. Убирание не
трогает оценки. Блок обновляется HTMX-фрагментом, без JS — полная страница.

### S-2.8 · admin · Нагрузка

На странице класса: таблица «предмет → учитель». Добавить: выбрать активный
предмет и активного учителя. Один учитель на пару (класс, предмет): выбор
предмета, который уже назначен, заменяет учителя. Убрать назначение —
уроки остаются у автора.

### S-2.9 · admin · Дети родителя

На странице родителя: список детей, добавить ученика (поиск по ФИО),
убрать. Один ученик может быть у нескольких родителей.

### S-2.10 · admin · Деактивировать пользователя

Когда админ деактивирует учителя. Тогда учитель исчезает из списков и
выборов, его сессии удалены, вход по его логину даёт «неверные данные».
Активировать обратно можно. Себя деактивировать нельзя.

### S-2.11 · admin · Задать пароль пользователю

На странице правки пользователя — отдельная форма «Новый пароль»; после
смены сессии пользователя удаляются.

### S-2.12 · любой · Сменить свой пароль

Страница `/account/password`: текущий пароль, новый, повтор. Неверный
текущий — ошибка. После смены прочие сессии пользователя удаляются, текущая
остаётся.

### S-2.13 · admin · Поиск и фильтры

Список учеников: поиск подстрокой по ФИО без учёта регистра, фильтр по
классу текущего года, переключатель «Показать удалённые». Учителя и
родители — поиск и переключатель. Пустой результат — сообщение, не пустая
таблица.

### S-2.14 · admin · Дашборд

Счётчики: классы текущего года, ученики в них, активные учителя, активные
предметы. Если в текущем году нет классов — над счётчиками баннер
«В 2026/2027 ещё нет классов» со ссылкой на создание класса.

### S-2.15 · teacher, student, parent · Дашборд и меню

Меню по D-033. Дашборд: приветствие и ссылка на «Журнал» или «Дневник»
(пока заглушка «в разработке»). `/admin/*` — 404.

### S-2.16 · негативные

- Ученик или учитель открывает `/admin/classes` — 404.
- Создание класса с занятым именем в том же году — ошибка формы.
- Добавление в класс ученика, уже состоящего в классе этого года — ошибка.
- Логин с пробелами или кириллицей — ошибка (допустимы `a-z0-9._-`).
