# Сценарии

Формат: `S-<итерация>.<номер>`, роль, «дано / когда / тогда», критерии
приёмки. Из каждого сценария пишется хотя бы один тест в файле теста
обработчика (`internal/server/<пакет>/<name>_test.go`) через `servertest.New`.
Негативные сценарии (чужие данные, чужая роль) обязательны.

Общие правила для всех сценариев итерации 2:

- Страницы `/admin/*` доступны только роли admin; другим ролям и анонимам —
  404 (аноним предварительно уходит на `/login`, как сейчас).
- Каждая форма отправляется обычным POST и работает без JS.
- Ошибки валидации показываются на той же странице, введённые значения
  сохраняются в полях.
- После успешного POST — редирект на страницу списка или карточки (PRG).
  HTMX-запрос к строчной форме получает фрагмент контейнера вместо
  редиректа (D-043); там, где меняется страница (создание пользователя,
  сброс и смена пароля), — `HX-Redirect` (см. `web.Redirect`).
- Вёрстка проверяется на ширине 375 px и 1280 px.

## Итерация 2 — справочники админа

### S-2.1 · система · Текущий учебный год по конфигу

Дано: `school.year_start_month: 8`. Когда сегодня 31.07.2026 — текущий год
2025 («2025/2026»); 01.08.2026 и 15.03.2027 — 2026 («2026/2027»). Год
считается в `timezone` из конфига. Покрывается тестом `school.YearAt`.

### S-2.2 · отменён (D-044) · Классы следующего года заранее

Классы создаются только в текущем году. Школа, которой нужно готовить
классы раньше 1 августа, сдвигает `school.year_start_month` в конфиге.

### S-2.3 · admin · Предметы

Создать «Алгебра», переименовать, деактивировать. Деактивированный не
показывается в списке без переключателя и недоступен для новой нагрузки;
существующие нагрузки и уроки с ним остаются. Имя уникально среди активных.

### S-2.4 · admin · Типы работ

Список содержит шесть стартовых типов из миграции в заданном порядке.
Админ добавляет «Проект» (встаёт в конец), переименовывает в строке,
двигает стрелками «выше»/«ниже», деактивирует. Деактивированный тип не предлагается в новых
оценках.

### S-2.5 · admin · Создать класс

Дано: сегодня 15.09.2026, текущий год 2026/2027. Когда админ создаёт класс
«7А». Тогда класс в списке текущего года. Классы создаются только в текущем
году; имя уникально внутри года. Список классов фильтруется по году
(вкладки — годы существующих классов и текущий), по умолчанию текущий;
на вкладках прошлых лет формы добавления нет.

### S-2.6 · admin · Создать учителя, ученика, родителя

Строка добавления сверху списка (D-047): ФИО, у ученика ещё необязательный
класс текущего года (D-046). Логин сервер собирает транслитом ФИО
(`ivanova.m`, при коллизии — суффикс `2`, `3`…), пароль генерирует (D-048).
После создания — страница «Пользователь создан» с логином и паролем один
раз; повторное открытие ведёт к списку.

Критерии: логин уникален среди всех пользователей (включая неактивных) и
правится в строке правки по правилу `a-z0-9._-`; роль задаётся разделом, в
форме её нет.

### S-2.7 · admin · Состав класса

На карточке активного класса текущего года: список учеников, поле
«добавить ученика» (выбор из активных учеников, не состоящих ни в одном
классе текущего года), кнопка «убрать». Ученик не может быть в двух
классах одного года. Убирание не трогает оценки. Блок обновляется
HTMX-фрагментом, без JS — редирект на карточку. Карточка прошлого года
или удалённого класса — только просмотр (D-049).

### S-2.8 · admin · Нагрузка

На той же карточке: список «предмет — учитель». Добавить: выбрать активный
предмет и активного учителя. Один учитель на пару (класс, предмет): выбор
предмета, который уже назначен, заменяет учителя. Убрать назначение —
уроки остаются у автора. Деактивированные предмет или учитель остаются в
списке с пометкой «удалён».

### S-2.9 · admin · Дети родителя

В строке правки родителя (`?edit={id}`, D-049): список детей с классом,
живой поиск ученика по ФИО и кнопка «Добавить» у найденных, «Убрать» у
детей. В обычной строке дети перечислены текстом. Один ученик может быть
у нескольких родителей.

### S-2.10 · admin · Деактивировать пользователя

Когда админ деактивирует учителя. Тогда учитель исчезает из списков и
выборов, его сессии удалены, вход по его логину даёт «неверные данные».
Активировать обратно можно. Себя деактивировать нельзя: админ не входит ни
в один раздел, а действие раздела над пользователем с другой ролью даёт 404.

### S-2.11 · admin · Сбросить пароль пользователю

Страница «Сброс пароля»: админ ищет пользователя по ФИО среди активных
учителей, учеников и родителей (список пуст, пока запрос пустой), у
найденного нажимает «Сбросить пароль» и подтверждает в окне с ФИО этого
пользователя. Сервер генерирует новый пароль, удаляет сессии пользователя
и показывает логин и пароль один раз на странице «Пароль изменён» (та же,
что после создания), откуда «К поиску» возвращает к тому же запросу.
Админа и удалённого пользователя сбросить нельзя: 404 и «не найден» в
поиске (D-056).

### S-2.12 · любой · Сменить свой пароль

Страница `/account/password` для учителя, ученика и родителя: текущий
пароль, новый, повтор. Неверный текущий, короче 8 символов или несовпадение
повтора — ошибка формы. После смены прочие сессии пользователя удаляются,
текущая остаётся. Админу страница отвечает 404 (D-050).

### S-2.13 · admin · Поиск и фильтры

Список учеников: поиск подстрокой по ФИО без учёта регистра, фильтр по
классу текущего года, переключатель «Показать удалённые». Учителя и
родители — поиск и переключатель. Пустой результат — сообщение, не пустая
таблица.

### S-2.14 · admin · Дашборд

Счётчики: классы текущего года, ученики в них, активные учителя, активные
предметы. Если в текущем году нет классов — над счётчиками баннер
«В 2026/2027 ещё нет классов» со ссылкой на создание класса.

### S-2.15 · teacher, student, parent · Дашборд и меню

Меню по D-033. Дашборд: приветствие и ссылка на «Журнал» или «Дневник»
(пока заглушка «в разработке»). `/admin/*` — 404.

### S-2.16 · негативные

- Ученик или учитель открывает `/admin/classes` — 404.
- Создание класса с занятым именем в том же году — ошибка формы.
- Удаление класса, в котором есть ученики — ошибка формы, класс остаётся
  (D-052).
- Добавление в класс ученика, уже состоящего в классе этого года — ошибка.
- Логин с пробелами или кириллицей — ошибка (допустимы `a-z0-9._-`).

## Итерация 3 — журнал учителя

Общие правила итерации 2 действуют. Дополнительно: `/journal/*` доступен
только роли teacher, `/admin/substitutions` — только admin; другим ролям
404. Чужой урок (учитель не автор и не текущий учитель по нагрузке) — 404,
сервис отдаёт `journal.ErrForbidden` (D-058). Журнал работает с текущим
учебным годом; год передаётся в сервис параметром (Q-31, D-058).

### S-3.1 · admin · Замены

Страница «Замены»: строка добавления «класс, предмет, учитель, с, по».
Класс — активный класс текущего года, предмет и учитель — активные, «с»
обязательна, «по» может быть пустой («до отмены»), «по» не раньше «с».
Периоды замен по одной паре (класс, предмет) не пересекаются: пересечение
— ошибка формы «Период пересекается с другой заменой». Строка текстом: класс,
предмет, ФИО учителя, период; «Изменить» правит только даты (так замена
закрывается), «Удалить» убирает строку после подтверждения, уроки остаются
у автора. Замены, у которых «по» раньше сегодня, скрыты за переключателем
«Показать завершённые». Деактивированный учитель или предмет остаётся в
строке с пометкой «удалён».

### S-3.2 · teacher · Пары в журнале

В списке «Класс · Предмет» на `/journal` учитель видит пары из своей
нагрузки по активным классам текущего года с активными предметами и пары
из замен, чей период не закончился («по» пустая или не раньше сегодня).
Список отсортирован по классу, потом по предмету. Учитель без нагрузки и
замен видит пустое состояние «Вам пока не назначены классы и предметы».

### S-3.3 · teacher · Открыть урок

Дано: у учителя нагрузка «7А · Алгебра». Когда он выбирает пару, дату
(по умолчанию сегодня) и нажимает «Открыть». Тогда создаётся урок с
автором-учителем и открывается его страница; повторное «Открыть» той же
тройки открывает тот же урок. Дата любая, будущая тоже (D-022).
Замещающий открывает урок только на дату внутри периода замены: иначе
ошибка «На эту дату замена не действует». Если урок на дату уже создан
другим учителем и по D-031 не виден замещающему — ошибка «Урок на эту дату
уже создал другой учитель». Пара не из списка — ошибка «Выберите класс и
предмет из списка».

### S-3.4 · teacher · Тема и удаление урока

На странице урока шапка «7А · Алгебра · 15.09.2026» и форма темы
(необязательный текст до 200 символов, «Сохранить»). Кнопка «Удалить урок»
есть только у пустого урока (без оценок и записей об уроке); после
подтверждения урок удаляется, редирект на `/journal`. POST удаления
непустого урока — ошибка «Урок с оценками или записями удалить нельзя».

### S-3.5 · teacher · Последние уроки

Под формой на `/journal` — список последних 15 уроков текущего года,
которые учитель видит (автор или текущий учитель по нагрузке), по дате
убыванию, при равной дате новые выше: дата, класс, предмет, тема; дата —
ссылка на урок. Пустой список — «Пока нет уроков».

### S-3.6 · teacher · Ученики урока

Слева (на телефоне — чипы над формой) текущий состав класса по ФИО плюс
все, у кого есть оценки или записи по уроку (D-023), вместе по алфавиту.
У каждого краткие отметки: значения оценок через запятую и «Н» при
отсутствии («5, 4 · Н»). Выбранный ученик (`?student={id}`, неизвестный
или пустой — первый в списке) подсвечен. Деактивированный
ученик — с пометкой «удалён»; ученик не из текущего состава — с пометкой
«не в классе», формы добавления оценки и записи у него нет, имеющиеся
оценки можно править и удалять.

### S-3.7 · teacher · Оценки

Справа у выбранного ученика список оценок урока (тип работы, значение,
подпись) и форма «тип работы (активные), значение 1–5, подпись до 100
символов, Поставить». «Изменить» (`?mark={id}`) рендерит одну оценку
формой в строке, «Удалить» убирает после подтверждения. Оценка со старым
деактивированным типом показывает его имя; в списке выбора его нет.
Ученик не в составе класса или значение вне 1–5 — ошибка формы. Успех —
HTMX-фрагмент `#lesson`, без JS — редирект на страницу урока с тем же
`student`.

### S-3.8 · teacher · Отсутствие и комментарий

Под оценками одна форма: флажок «Отсутствовал», комментарий до 500
символов, «Сохранить». Сохранение с пустым комментарием и снятым флажком
удаляет строку `lesson_students`. Отсутствие не запрещает оценки. Формы
нет у ученика «не в классе»; POST для него — ошибка «Ученик не в классе».

### S-3.9 · негативные

- Ученик, родитель или админ открывает `/journal` — 404; учитель —
  `/admin/substitutions` — 404.
- Учитель открывает урок другого учителя по паре не из своей нагрузки —
  404; то же для POST оценок, записи, темы и удаления.
- Замещающий после окончания замены открывает урок, который сам создал —
  видит (автор); урок основного учителя на той же паре — 404.
- Основной учитель по нагрузке видит и правит уроки, созданные
  замещающим (D-031).
- Оценка ученику, которого нет в списке урока, — ошибка; ученику «не в
  классе» — ошибка «Ученик не в классе».
- Замена с «по» раньше «с», с пересечением периода, на класс прошлого
  года — ошибка формы.

### S-3.10 · teacher · Дашборд

Карточка «Журнал» на дашборде ведёт на `/journal` без подписи «в
разработке»; заглушка `/journal` из корня `server` удалена, `/diary`
остаётся заглушкой до итерации 4.
