# Интерфейс

Оболочка `layout.App` остаётся: сайдбар слева на десктопе, выдвижное меню на
телефоне. Меню строится по роли (D-033). Все страницы админа живут под
`/admin`, страница смены пароля — `/account/password`.

## Меню

| Роль | Пункты |
|---|---|
| admin | Дашборд `/`, Классы `/admin/classes`, Предметы `/admin/subjects`, Учителя `/admin/teachers`, Ученики `/admin/students`, Родители `/admin/parents`, Типы работ `/admin/work-types` |
| teacher | Дашборд `/`, Журнал `/journal` (заглушка до итерации 3) |
| student, parent | Дашборд `/`, Дневник `/diary` (заглушка до итерации 4) |

В шапке или внизу сайдбара: ФИО, роль, ссылка «Сменить пароль», кнопка
«Выйти».

## Маршруты итерации 2

```
GET  /admin/subjects?inactive=1&edit={id}   одна страница: форма добавления, строки текстом, `edit` — одна строка формой (D-043)
POST /admin/subjects, /{id}, /{id}/deactivate, /{id}/activate
GET  /admin/work-types?inactive=1      то же, плюс POST /{id}/up, /{id}/down — порядок стрелками
GET  /admin/classes?year=2026&inactive=1&edit={id}   список по году как у предметов (D-043, D-044): вкладки-ссылки лет (годы существующих классов и текущий), строка добавления только в текущем году, `edit` — одна строка формой
POST /admin/classes?year=2026, /{id}?year=…, /{id}/deactivate?year=…, /{id}/activate?year=…   класс создаётся в текущем году; `year` в адресе — для списка и редиректа
GET  /admin/classes/{id}               карточка класса
POST /admin/classes/{id}/students      добавить ученика (student_id)
POST /admin/classes/{id}/students/{sid}/remove
POST /admin/classes/{id}/assignments   назначить (subject_id, teacher_id)
POST /admin/classes/{id}/assignments/{aid}/remove

GET  /admin/teachers?q=&inactive=1     список; аналогично /students (+class={id}), /parents
GET  /admin/{teachers|students|parents}/new, /{id}/edit
POST /admin/{teachers|students|parents}, /{id}, /{id}/password, /{id}/deactivate, /{id}/activate
GET  /admin/{teachers|students|parents}/{id}/created   логин и пароль один раз (данные — из одноразовой записи в сессии, не из URL)
POST /admin/parents/{id}/children, /admin/parents/{id}/children/{sid}/remove

GET  /account/password, POST /account/password
```

Действия, меняющие состояние, — только POST; «удалить/убрать» — кнопки в
форме, не ссылки. Ответы на HTMX-запросы для блоков состава, нагрузки и
детей — фрагмент блока; без `HX-Request` — редирект на карточку.

## Макеты

Общий список справочника (десктоп):

```
┌ Ученики ─────────────────────────────────────────── [+ Добавить] ┐
│ [поиск по ФИО…] [Класс: все ▾] [ ] показать удалённые            │
├──────────────────────────────┬─────────┬───────────┬─────────────┤
│ ФИО                          │ Класс   │ Логин     │             │
│ Иванова Мария Петровна       │ 7А      │ ivanova.m │ Изменить    │
│ Петров Иван Сергеевич  неакт.│ —       │ petrov.i  │ Изменить    │
└──────────────────────────────┴─────────┴───────────┴─────────────┘
```

Тот же список на телефоне — строки складываются в карточки:

```
┌ Ученики            [+] ┐
│ [поиск по ФИО…]        │
│ [Класс ▾] [ ] неактив. │
├────────────────────────┤
│ Иванова Мария Петровна │
│ 7А · ivanova.m         │
│              Изменить →│
├────────────────────────┤
│ Петров Иван Сергеевич  │
│ удалён · petrov.i      │
└────────────────────────┘
```

Карточка класса:

```
┌ 7А · 2026/2027                                   [Изменить] ┐
│                                                             │
│ Ученики (24)                    │ Предметы и учителя        │
│ Иванова Мария        [убрать]   │ Алгебра   Сидорова А.А. [убрать] │
│ Козлов Пётр          [убрать]   │ История   Кузнецов В.П. [убрать] │
│ …                               │                           │
│ [выбрать ученика ▾] [Добавить]  │ [предмет ▾] [учитель ▾] [Назначить] │
└─────────────────────────────────────────────────────────────┘
```

На телефоне колонки идут одна под другой: сначала ученики, потом предметы.
Список классов: под заголовком ряд вкладок-ссылок «2025/2026 · 2026/2027»,
ниже (только в текущем году) строка «название + Добавить» и строки с
«Изменить» и «Удалить», как у предметов; имя класса — ссылка на карточку,
на карточке кнопки «Изменить» нет.

Форма пользователя (одна для трёх разделов, у ученика добавляется класс):

```
┌ Новый ученик ───────────────────────┐
│ ФИО        [Иванова Мария Петровна] │
│ Логин      [ivanova.m            ]  │  ← заполняется из ФИО, редактируемо
│ Пароль     [••••••••             ]  │
│ Класс      [7А (2026/2027)     ▾ ]  │  ← только у ученика, необязательно
│                  [Отмена] [Создать] │
└─────────────────────────────────────┘
```

Страница после создания:

```
┌ Ученик создан ──────────────────────┐
│ Иванова Мария Петровна              │
│ Логин   ivanova.m                   │
│ Пароль  Kx7#pq2m   (показан один раз)│
│ Передайте данные ученику.           │
│           [К списку] [Ещё ученика]  │
└─────────────────────────────────────┘
```

Автозаполнение логина: ФИО и логин вводятся в одной форме, поэтому транслит
делается маленькой функцией в `static/js/app.js` по data-атрибуту поля (CSP
запрещает инлайн). Без JS поле остаётся пустым, и сервер генерирует логин сам
той же функцией на Go. Результат одинаковый, JS необязателен.

Правка пользователя — та же форма без пароля, плюс отдельный блок:

```
│ Новый пароль [••••••••] [Сменить]    │
│ Статус: активен          [Удалить] │
```

Смена своего пароля `/account/password`: текущий, новый, повтор, кнопка.

## Состояния

- Пустой список: «Пока нет учеников» и кнопка добавления.
- В текущем году нет классов: на дашборде баннер «В 2026/2027 ещё нет классов»
  со ссылкой на создание класса; список классов — пустое состояние.
- Ошибка формы: красная строка под полем, значения полей сохранены.
- Деактивированная запись в списке: серый текст и метка «удалён»; кнопки
  «Удалить» и «Восстановить» (в коде — deactivate/activate, D-018).
